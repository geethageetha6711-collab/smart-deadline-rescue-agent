      LangGraph Agent Architecture & State Flow

      START
      ↓
      1. Task Input Validator
      ↓
      2. Deadline Risk Analyzer
      ↓
      3. Workload Estimator
      ↓
      4. Priority Decision Engine
      ↓
      5. Recovery Plan Generator
      ↓
      6. Schedule Feasibility Checker
      ↓ Overload / Conflicts (<3 cycles)
      7. Plan Optimizer (Bounded Retry ≤ 3)
      ↑ re-generates schedule
      ↓ Feasible or Max Cycles Reached
      8. Final Plan Evaluator
      ↓
      9. Report Generator (Gemini / Fallback)
      ↓
      END

      Workflow Verification Details

      • Real LangGraph Workflow: Compiled StateGraph with 9 discrete nodes, conditional edges, and shared typed state.
      • Bounded Retry Loop: Automatically halts after 3 optimization attempts to avoid infinite recursion.
      • Honest Infeasibility: If workload cannot fit before deadlines, accurately classifies plan as INFEASIBLE_OVERLOADED rather than claiming false feasibility.
      • Dual Reasoning: Google Gemini API generates natural-language insights; deterministic engine seamlessly steps in if key is unset.
